## Overview

因果律消除 is a WeChat Mini Game that innovates on both the gameplay layer and the operation layer of casual puzzle games. The core mechanic — dragging cause tiles onto effect tiles with time-rewind consequences — has no equivalent in the market. Every completed level generates a unique "causal chain path diagram" that serves as both a shareable artifact and a competitive ranking dimension.

## Game Pillars

| Pillar | Description |
|--------|-------------|
| **One-sentence rules** | "Drag a cause to its matching effect — but every elimination rewinds time" — understood in 3 seconds |
| **Mastery takes a lifetime** | The butterfly effect of causal chains makes every move a deep reasoning exercise with no skill ceiling |
| **Every session tells a story** | Each player's causal chain path is unique; the post-level diagram is their personal narrative |
| **Sharing IS content** | Causal chain path diagrams have inherent narrative tension — "Look how I untangled this in 5 moves" |
| **Multi-dimensional competition** | Players compete not just on "cleared or not" but on least moves, shortest causal chain, fewest rewinds, fastest time |

## Target Audience

- WeChat users who play casual puzzle games (羊了个羊's 100M+ player base)
- Players who want more intellectual depth than pure luck-based puzzles
- Competitive players who enjoy optimizing solutions (speedrunners, min-maxers)

## Core Loop

```
Select Level → Analyze Board → Drag Cause to Effect → Watch Rewind Ripple →
  → (Repeat until win or deadlock) →
  → Win: View Causal Chain Path Diagram → Share / Next Level
  → Deadlock: Use Item / Share Revive / Restart
```

## Visual Identity

**One-line visual rule**: Deep cosmic sci-fi with semi-transparent glass cards — the "causal time manipulation" aesthetic.

**Supporting principles**:
1. Dark backgrounds with colored atmospheric glows (halo + orbs + particles)
2. Semi-transparent frosted glass cards for all UI panels
3. Cool spectrum for normal play (blue/teal/purple), warm for alerts (gold/amber), danger for failures (red)
4. Rewind animations use expanding ripple waves that convey "time flowing backwards"

## Differentiation from 羊了个羊

| Dimension | 羊了个羊 | Causal Chain Elimination |
|-----------|---------|--------------------------|
| Core mechanic | Tap three-match | Drag cause→effect with time rewind |
| Failure source | Random luck (level 2 near-impossible) | Reasoning error (miscalculated rewind chain) |
| Learnability | Zero (pure luck) | Learnable — failures teach chain reasoning |
| Share content | Progress screenshot | Unique causal chain path diagram |
| Competition | Cleared or not | Multi-dimensional (moves, chain length, rewinds, time) |
